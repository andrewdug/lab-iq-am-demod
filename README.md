# Формирование НЧ квадратурных составляющих и демодуляция АМ (Qucs-S)

Лабораторная работа «Формирование низкочастотных квадратурных составляющих и демодуляция АМ сигнала», бригада N = 1. Моделирование в Qucs-S (симулятор qucsator).

## Исходные данные

| Параметр | Значение |
|---|---|
| Несущая f0 = 400 + 30·N | 430 МГц |
| Частота модуляции Fм = 3·N | 3 МГц |
| Амплитуда несущей U0, коэффициент модуляции m | 1 В, 1 |
| Вторая АМ (п. 3–5) | f2 = f0 + 40 = 470 МГц, Fм2 = 5 МГц |
| Опорный генератор (гетеродин) | 20 В, фазы 0° (I) и 90° (Q) |

## Схемы (`qucs/`)

| Файл | Что моделирует |
|---|---|
| `LR2k5_N1_1AM.sch` | п. 1–2: одна АМ, полная синхронизация, RC-ФНЧ, цифровая демодуляция по отсчётам |
| `LR2k5_N1_1AM_pi4.sch` | то же при разности фаз π/4 (фазы опорных −45° / 45°) |
| `LR2k5_N1_rc.sch` | п. 3–4: сумма двух АМ, RC-ФНЧ |
| `LR2k5_N1_lc.sch` | п. 5: сумма двух АМ, LC-фильтр Чебышёва 5-го порядка |
| `LR2k5_N1_filter_RC.sch`, `LR2k5_N1_filter_LC.sch` | АЧХ и групповая задержка фильтров отдельно |
| `LR2k5_N1_hilbert_AC.sch` | КИХ-фильтр Гильберта 10-го порядка: АЧХ/ФЧХ, без окна и с окном Хэмминга |
| `LR2k5_N1_hilbert_TR.sch` | тот же фильтр во времени: огибающая √(x² + H{x}²) для нашей АМ |
| `extra/` | исходная схема и промежуточные варианты (N = 2, общий файл) |

Результаты (`*.dat`) в репозиторий не входят: откройте схему в Qucs-S и запустите моделирование (F2). Расчёт схем со смесителями занимает 8–17 мин.

## Расчёт

**Смеситель** — два диодных кольца (двойной балансный), гетеродин ≫ пика сигнала U0(1 + m) = 2 В. Выход I = K·U(t)·cos φ0, Q = K·U(t)·sin φ0; реальный K ≈ 0,083 (идеальный ключ 2/π ≈ 0,64).

**RC-ФНЧ** из условия K(Fм) = 0,95: τ = √(1/0,95² − 1)/(2πFм) = 17,44 нс; R = 1 кОм, C = 17,44 пФ, fc = 9,13 МГц. K(2f0) = 0,0106 (−39,5 дБ), K(40 МГц) = 0,222 (−13 дБ).

**LC-фильтр** Чебышёва 5-го порядка, неравномерность 0,446 дБ, fc = 3 МГц, Rs = Rн = 50 Ом: C1 = C5 = 1,7506 нФ, L2 = L4 = 3,309 мкГн, C3 = 2,634 нФ.

**Цифровая демодуляция** (уравнения Qucs): 20 отсчётов на период Fм (f_д = 60 МГц, T_д = 16,67 нс), `In`/`Qn` через `interpolate`, `Un = sqrt(In^2+Qn^2)`, спектр `Time2Freq` (шаг 0,5 МГц). Синхронный случай: среднее 0,083 В, восстановленный m ≈ 0,94 (теория m·K(Fм) = 0,95). Модулирующее напряжение `Uenv = U0·(1 + m·sin 2πFм·t)` (источник модуляции в Qucs синусный).

**Фильтр Гильберта**: fs = 4·f0 = 1720 МГц, Δt = 0,5814 нс; h[k] = 2/(πk) для нечётных k = ±1, ±3, ±5; окно Хэмминга w[n] = 0,54 − 0,46·cos(2πn/10).

|---|---|---|
| \|K\| | 1,1035 | 1,0129 |
| Разность фаз с задержкой 5Δt | −90° | −90° |
| СКО ошибки огибающей | 6,4 % | 0,8 % |

## Скрипты (`scripts/`)

- `iq_demod.m` — демодуляция в MATLAB/Octave по CSV, экспортированным из графиков I и Q.
- `gen_hilbert.sh` — генератор схем фильтра Гильберта: `bash gen_hilbert.sh AC|TR <файл.sch>`.
