# Формирование НЧ квадратурных составляющих и демодуляция АМ (Qucs-S)

Лабораторная работа «Формирование низкочастотных квадратурных составляющих и демодуляция АМ сигнала», бригада N = 1. Моделирование в Qucs-S (симулятор qucsator).

## Исходные данные

| Параметр | Значение |
|---|---|
| Несущая f0 = 400 + 30·N | 430 МГц |
| Частота модуляции Fм = 3·N | 3 МГц |
| Амплитуда несущей U0, коэффициент модуляции m | 1 В, 1 |
| Вторая АМ (п. 3–5) | f2 = f0 + 40 = 470 МГц, Fм2 = 5 МГц |
| Опорный генератор (гетеродин) | 20 В, фазы 0° (I) и 90° (Q) |

## Схемы (`qucs/`)

| `LR2k5_N1_1AM_pi4.sch` | то же при разности фаз π/4 (фазы опорных −45° / 45°) |

| `LR2k5_N1_hilbert_TR.sch` | те же фильтры во времени: s(t), s′(t) = s(t − t0), ŝ(t), огибающая √(s′² + ŝ²) |

Результаты (`*.dat`) в репозиторий не входят: откройте схему в Qucs-S и запустите моделирование (F2). Расчёт схем со смесителями занимает 8–17 мин.

## Расчёт

**Смеситель** — два диодных кольца (двойной балансный), гетеродин ≫ пика сигнала U0(1 + m) = 2 В. Выход I = K·U(t)·cos φ0, Q = K·U(t)·sin φ0; реальный K ≈ 0,083 (идеальный ключ 2/π ≈ 0,64).

**RC-ФНЧ** из условия K(Fм) = 0,95: τ = √(1/0,95² − 1)/(2πFм) = 17,44 нс; R = 1 кОм, C = 17,44 пФ, fc = 9,13 МГц. K(2f0) = 0,0106 (−39,5 дБ), K(40 МГц) = 0,222 (−13 дБ).

**LC-фильтр** Чебышёва 5-го порядка, неравномерность 0,446 дБ, fc = 3 МГц, Rs = Rн = 50 Ом: C1 = C5 = 1,7506 нФ, L2 = L4 = 3,309 мкГн, C3 = 2,634 нФ.

**Цифровая демодуляция** (уравнения Qucs): 20 отсчётов на период Fм (f_д = 60 МГц, T_д = 16,67 нс), `In`/`Qn` через `interpolate`, `Un = sqrt(In^2+Qn^2)`, спектр `Time2Freq` (шаг 0,5 МГц). Синхронный случай: среднее 0,083 В, восстановленный m ≈ 0,94 (теория m·K(Fм) = 0,95). Модулирующее напряжение `Uenv = U0·(1 + m·sin 2πFм·t)` (источник модуляции в Qucs синусный).

### Фильтр Гильберта (занятие «Формирование НЧ квадратурных составляющих с помощью цифрового фильтра Гильберта»)

**П. 1, частота дискретизации** fs = 4·f0 = 1720 МГц, Δt = 0,5814 нс. АЧХ КИХ-фильтра Гильберта нечётной длины с антисимметричной ИХ равна нулю на 0 и fs/2 и симметрична относительно fs/4, где её нечётные производные равны нулю. Эта точка — середина области равномерности и дальше всего отстоит от спадов к 0 и fs/2, поэтому несущая ставится именно туда: f0 = fs/4. Полоса сигнала f0 ± Fм = 427…433 МГц занимает 0,35 % от fs/2 и целиком лежит в этой области. Условие Котельникова fs > 2(f0 + Fм) выполняется с запасом. Кроме того, ω0Δt = π/2, так что cos/sin в п. 7 принимают значения 1, 0, −1, 0.

**П. 2, коэффициенты** (N = 11, n0 = 6): h(n) = 2/(π(n − n0)) при нечётном n − n0 и 0 при чётном. Получается −0,1273; 0; −0,2122; 0; −0,6366; 0; 0,6366; 0; 0,2122; 0; 0,1273. Ненулевые отсчёты стоят на задержках 0, 2Δt, …, 10Δt, поэтому линия задержки собрана из звеньев по 2Δt. Теоретическая задержка t0 = (n0 − 1)·Δt = 5Δt = 2,907 нс.

**П. 4, окно Хэмминга** w(n) = 0,54 − 0,46·cos(2π(n − 1)/(N − 1)): 0,08; 0,398; 0,912; 1; 0,912; 0,398; 0,08 (для ненулевых отсчётов). Порядок выбирается по допустимой неравномерности |K| в полосе сигнала. Разбаланс ε = |K(f0)| − 1 между s′ и ŝ даёт зеркальную составляющую на −f0 уровнем 20·lg(ε/2) и ошибку огибающей того же порядка. При требовании |ε| < 1 % порядка 10 с окном Хэмминга не хватает (ε = 1,29 %), поэтому порядок увеличен до 18 (N = 19, n0 = 10, t0 = 9Δt = 5,233 нс). Ненулевые отсчёты остаются на чётных задержках, линия задержки та же. Коэффициенты с окном: ∓0,0057; ∓0,0171; ∓0,0586; ∓0,1634; ∓0,6190 (антисимметрично). Порядки 12 и 16 выбраны не были: при чётном n0 − 1 ненулевые отсчёты попадают на нечётные задержки, и пришлось бы строить другую линию задержки.

**П. 5–8** считаются в MATLAB (`scripts/hilbert_iq.m`). Скрипт читает `LR2k5_N1_hilbert_TR.dat`, берёт отсчёты с шагом Δt (шаг TR равен Δt/12, поэтому отсчёты попадают точно в сетку) и выполняет следующее:
- измеряет t0 по МНК-совмещению ŝ(t) с эталонным H{s}(t − τ), где эталон получен через БПФ (на 2 мкс укладывается целое число периодов f0 и Fм);
- формирует z(n) = s′(n) + j·ŝ(n), находит разность фаз и строит годограф. При fs = 4f0 точки лежат на осях, потому что фаза растёт на 90° за отсчёт, а |z| = U(n);
- строит двусторонние спектры s и z в окне 1 мкс = 1720 отсчётов с шагом 1 МГц, так что f0 и f0 ± Fм попадают точно в бины ДПФ;
- вычисляет I(n), Q(n) по формулам задания. Теория: z·e^{−jω0t} = −j·U(t − t0)·e^{−jω0t0}, и при ω0t0 = 9π/2 (или 5π/2) получается I = −U(t − t0), Q = 0, что совпадает с моделированием;
- считает U(n) = √(I² + Q²) и сравнивает её с U0(1 + m·sin 2πFм(t − t0)).

Остаточная ошибка U(n) меняет знак от отсчёта к отсчёту (частота fs/2). Это след разбаланса |K(f0)| ≠ 1.

## Скрипты (`scripts/`)

- `iq_demod.m` — демодуляция в MATLAB/Octave по CSV, экспортированным из графиков I и Q.
- `gen_hilbert.sh` — генератор схем фильтра Гильберта: `bash gen_hilbert.sh AC|TR <файл.sch>`.
- `hilbert_iq.m` — п. 5–8 занятия по фильтру Гильберта: запуск из папки с `LR2k5_N1_hilbert_TR.dat` (MATLAB R2018b+, без тулбоксов). Сохраняет `hilbert_iq_{signals,hodograph,spectra,iq,demod}.png` и `hilbert_iq.csv`, итоговый фильтр задаётся переменной `iMain`. Моделирование TR занимает около 1,5 мин, скрипт — около 1 мин.
