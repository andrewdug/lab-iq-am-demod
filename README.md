# Лабораторная работа: Формирование низкочастотных квадратурных составляющих сигнала с помощью цифрового фильтра Гильберта (Qucs-S & GNU Octave / MATLAB)

## Исходные данные (Бригада $M = 1$)
- **Несущая частота АМ-колебания:** $f_0 = 400 + 30 \cdot M = 430\text{ МГц}$
- **Частота модулирующего сигнала:** $F_{\text{м}} = 3 \cdot M = 3\text{ МГц}$
- **Глубина АМ-модуляции:** $m = 100\%$ ($1.0$), амплитуда несущей $U_0 = 1\text{ В}$
- **Частота дискретизации:** $f_{\text{д}} = 4 f_0 = 1720\text{ МГц}$ ($1.72\text{ ГГц}$) — выбрана из условия расположения несущей частоты $f_0$ в центре плоской вершины АЧХ фильтра Гильберта ($f_0 = f_{\text{д}}/4$)
- **Период дискретизации:** $\Delta t_{\text{д}} = 1/f_{\text{д}} \approx 581.395\text{ пс}$ (шаг между ненулевыми отводами $2\Delta t_{\text{д}} \approx 1.1628\text{ нс}$)
- **Теоретическое время задержки фильтра 10-го порядка ($N=11, n_0=6$):** $t_0 = (n_0 - 1)\Delta t_{\text{д}} = 5\Delta t_{\text{д}} \approx 2.907\text{ нс}$

---

## Структура файлов проекта

Каждая модель фильтра и демодулятора выделена в отдельный файл схемы Qucs-S (`.sch`) с предрассчитанным набором данных (`.dat`):

1. **`1_Hilbert_FIR10_Rect.sch`** (`.dat`) — КИХ-фильтр Гильберта **10-го порядка без весового окна** (прямоугольное окно) и линия задержки $t_0 = 5\Delta t_{\text{д}}$ (пункты 2, 3, 5).
2. **`2_Hilbert_FIR10_Hamming.sch`** (`.dat`) — КИХ-фильтр Гильберта **10-го порядка с весовым окном Хэмминга** (пункты 4, 5), включая сравнение АЧХ и ФЧХ с фильтром без окна на одной координатной плоскости.
3. **`3_Hilbert_FIR14_Hamming_IncreasedOrder.sch`** (`.dat`) — КИХ-фильтр Гильберта **увеличенного (14-го) порядка с окном Хэмминга** ($N = 15, n_0 = 8, t_0 = 7\Delta t_{\text{д}} \approx 4.070\text{ нс}$) с расширенной полосой пропускания (пункт 4).
4. **`4_Hilbert_IQ_Demodulator.sch`** (`.dat`) — Полная схема формирования аналитического сигнала $z(t)$, низкочастотных квадратурных составляющих $I(t), Q(t)$ и цифрового амплитудного демодулятора $U(t) = \sqrt{I^2(t) + Q^2(t)}$ (пункты 6, 7, 8).
5. **`process_hilbert_lab.m`** (со вспомогательными функциями `loadQucsDataSet.m` и `getQucsVariable.m`) — скрипт цифровой постобработки для **GNU Octave / MATLAB**, который строит все графики по пунктам 3–8 и выводит расчетные таблицы коэффициентов.
