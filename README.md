# Формирование НЧ квадратурных составляющих с помощью цифрового фильтра Гильберта (Qucs-S)

Занятие для бригады M = 1: f0 = 430 МГц, Fм = 3 МГц, АМ со 100-процентной модуляцией, U0 = 1 В.

**Отчёт:** `report/Otchet_Hilbert_brigada1.docx` (и `.pdf`). Титульные данные заполняются вручную.

## Схемы (`qucs/`)

| Файл | Содержание |
|---|---|
| `LR2k5_N1_hilbert_AC.sch` | КИХ-фильтры Гильберта (порядок 10 без окна, порядки 10, 14, 18 с окном Хэмминга): АЧХ, ФЧХ, групповая задержка на 1 кГц…860 МГц, таблица значений на f0 |
| `LR2k5_N1_hilbert_TR.sch` | те же фильтры во времени: s(t), s′(t) = s(t − t0), ŝ(t), огибающая √(s′² + ŝ²) |

Схемы рассчитаны на симулятор **Qucsator-RF**: перед запуском выберите его в Qucs-S как симулятор по умолчанию. Запуск: F2. AC считается несколько секунд, TR около 15 минут.

Устройство схем (по образцу модели из презентации ex5):
- линия задержки D1…D9 из блоков `VDelay` (библиотека Ideal), Tdel = 2Δt; узлы x0, x2, …, x18;
- ряды усилителей с коэффициентами фильтра: G (порядок 18), O (порядок 14, итоговый), W (порядок 10 с окном), H (порядок 10 без окна). Усилитель — ИНУН без задержки;
- сумматоры: цепочки блоков `VSum` в каждом ряду;
- линия задержки исходного сигнала: D0 = 5Δt → xd, D0 + D14 = 5Δt + 2Δt → xd14, D18 = 9Δt → xd18;
- нагрузки 1 МОм нужны только для вывода напряжений.

## Расчёт и результаты

fд = 4·f0 = 1720 МГц, Δt = 0,5814 нс. Несущая стоит в центре области равномерности АЧХ (fд/4), а ω0Δt = π/2.

Критерий выбора порядка: разбаланс |ε| = ||K(f0)| − 1| ≤ 1 % (зеркальная составляющая не выше −46 дБ). Минимальный подходящий порядок на линии с чётными отводами равен 14. Итоговый фильтр: порядок 14, окно Хэмминга, N = 15, n0 = 8, t0 = 7Δt = 4,070 нс. Порядок 18 смоделирован для оценки запаса. Сводные таблицы находятся в отчёте и в `report/figures/results.json`.

### Особенность Qucsator при задержке 7Δt

Одиночный блок `VDelay` с Tdel = 7Δt дал в TR отдельные неверные точки: до 0,25 В в 119 точках из 41281. Блоки на 2Δt, 5Δt и 9Δt при тех же условиях работают с точностью около 10⁻¹² В. Поэтому задержка 7Δt собрана каскадом 5Δt + 2Δt. Причина внутри симулятора не исследовалась.

## Модель Simulink (`simulink/`)

`hilbert_iq_sl.slx` — цифровая обработка п. 6–8 (MATLAB R2025a, нужен DSP System Toolbox для блока Spectrum Analyzer): z(n), I/Q, АМ-демодулятор, годографы z(n) и I-Q (XY Graph), спектр z(n), осциллографы. Модель открывается из любой папки и запускается кнопкой Run. Данные лежат в `qucs_data.mat`, повторно считать Qucs-S не нужно.

Вариант фильтра задаётся переменной `iVar` в рабочем пространстве: 1 — порядок 10 без окна, 2 — порядок 10 с окном, 3 — порядок 14 с окном (по умолчанию), 4 — порядок 18 с окном.

- `run_hilbert_sl.m` — прогон всех вариантов, графики `sl_*.png` и ГВЗ, таблица `sl_results.json` (`report/figures`);
- `qucs_to_mat.m` — передача результатов Qucs-S в `qucs_data.mat` (нужна только после нового моделирования);
- `build_hilbert_sl.m` — сборка модели из скрипта;
- `save_model_images.m` — изображения модели для отчёта (нужен дисплей, не `-batch`).

## Скрипты (`scripts/`)

- `gen_hilbert.sh` — генератор схем: `bash scripts/gen_hilbert.sh AC|TR <файл.sch>`.
- `hilbert_iq.py` — цифровой обработчик п. 3–8 (Python, numpy, matplotlib): читает `.dat`, строит рисунки и `results.json`.
- `build_report.py` — сборка отчёта из `report/figures` (python-docx).
- `hilbert_iq.m` — обработчик для MATLAB, итоговый фильтр задаётся `iMain`.
- `iq_demod.m` — демодуляция в MATLAB/Octave по CSV, экспортированным из графиков I и Q.

Воспроизведение:

```bash
python scripts/hilbert_iq.py --dat qucs --out report/figures
python scripts/build_report.py
```

`.dat` не хранятся в репозитории: они появляются рядом со схемой после моделирования.
